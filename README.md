# 🏷️ Open Graph & Social Meta Tag Generator

An interactive SEO utility to generate Open Graph (`og:`), Twitter Card meta tags, and Schema.org JSON-LD structured markup with live real-time visual previews.

## 🚀 Key Features

- **Multi-Platform Visual Previews:** Real-time visual card rendering for Facebook / LinkedIn feeds and Google Search Snippets.
- **Open Graph Meta Tag Generator:** Generates `og:title`, `og:description`, `og:url`, `og:image`, and `og:site_name`.
- **Twitter Card Support:** Formats `twitter:card`, `twitter:site`, and image assets for large & small cards.
- **Schema.org JSON-LD Output:** Generates structured JSON-LD data for `WebSite`, `Article`, and `SoftwareApplication` entities.
- **One-Click Code Copy:** Easily copy clean HTML `<head>` tags directly into your web projects.
- **Dark Glassmorphism UI:** Modern, responsive dark mode design.
- **Zero External Dependencies:** Built with pure vanilla HTML5, CSS3, and JavaScript.
